## Что покрывает Vitest

1. Создание, изменение и перезапуск SQLite с фотографией и тегами.
2. Изучение ровно трёх из десяти, сохранение оценок, запрет оценки чужой карточки и завершённой сессии, отсутствие двойного учёта повторной оценки.
3. Подборка ссылается на исходную карточку; дублирование, перемещение и каскадное удаление.
4. Откат неуспешного перемещения и отклонение некорректных данных.
5. Сохранение общей фотографии при удалении одной копии; очистка неиспользуемого файла после 24 часов.
6. Отдельная установка/удаление демонстрационных наборов без изменения пользовательских.
7. ZIP round trip с новым UUID: формула, фотография, теги, подборка, история.
8. Импорт в независимую базу и экспорт только выбранного набора.
9. Отклонение повреждённой контрольной суммы без частичного импорта.
10. Отклонение неизвестного ZIP-пути, отсутствующих связей и неподдерживаемой версии манифеста.
11. Отклонение завышенного распакованного размера до распаковки.
12. Прямой/обратный диапазон и перемешивание без потери/дублирования элементов.
13. Отклонение некорректного JSON rich text, который мог бы нарушить работу редактора.
14. Все семь формул демонстрационных карточек проходят KaTeX с `throwOnError:true`.

## Исправления, найденные во время проверки

- Запрещённое CSP встраивание маленького KaTeX-шрифта как data URL: Vite теперь всегда выпускает шрифты отдельными локальными файлами.
- Параметр `directories` от `npm init` конфликтовал с electron-builder: удалён из корневой конфигурации, выходные пути заданы в `build.directories`.
- Для Vite React Refresh настроен nonce; production CSP остаётся без разрешения inline-скриптов.
- Предупреждение при закрытии несохранённой карточки перенесено также в обработчик Electron `will-prevent-unload`.
- Ошибки операций отображаются модальным диалогом, в том числе поверх формы, вместо уведомления за верхним слоем dialog.
- Стабилизированы E2E-фикстура PNG и ожидание готовности карточки перед проверкой скролла.

## Что ещё не подтверждено

Windows 10/11, запуск NSIS, установка/обновление/удаление на этих ОС и portable EXE локально не проверялись. Workflow Windows включает сборку, E2E, запуск упакованного EXE, silent-установку NSIS и запуск установленного приложения, затем загрузку EXE в Artifacts. Успешный запуск этого workflow нужно получить после загрузки проекта на GitHub. Подписи издателя нет.

Сборка Vite сообщает о JS-chunk примерно 964 КБ до gzip (около 299 КБ gzip), в который входят редактор и KaTeX. Это предупреждение о размере, не ошибка сборки; сетевой загрузки при работе нет. Node 22 сообщает experimental warning для встроенного `node:sqlite`; тесты выполняются успешно. Полный npm audit оставляет умеренные предупреждения в цепочке упаковщика; downgrade electron-builder ради автоматического audit fix не выполнялся.
